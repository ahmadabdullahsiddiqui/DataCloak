Datenschutz – technische Dokumentation

Diese Seite beschreibt in technischer Form, wie DataCloak mit Daten umgeht.

Klartext-Aussage

Dokumente werden lokal in Ihrem Browser verarbeitet und nicht zur Dokumentverarbeitung an unseren Server oder externe KI-Dienste übertragen.

Wir vermeiden bewusst pauschale Aussagen wie „100 % DSGVO-konform“. Die Architektur ist auf Privacy by Design ausgelegt; die endgültige DSGVO-Bewertung hängt zusätzlich von Betrieb, Hosting, Logging, Verarbeitungsverzeichnis, Datenschutzerklärung und organisatorischen Maßnahmen ab.

Welche Daten verarbeitet werden

  • das geöffnete Dokument und der daraus extrahierte Text,
  • die darin erkannten personenbezogenen Daten (Treffer),
  • die Ersetzungs-/Mapping-Tabelle (Original → Ersetzung),
  • das erzeugte Ausgabedokument.

Wo die Verarbeitung stattfindet

Vollständig in Ihrem Browser – im Hauptthread und in einem lokalen Web Worker. Es gibt keine serverseitige Verarbeitung und keine externe KI.

Welche Netzwerkverbindungen die Anwendung aufbaut

  • Beim Laden: HTTPS-GET-Anfragen für die eigenen statischen Dateien (HTML, CSS, JS, Icons) vom Host der App.
  • Während der Dokumentverarbeitung: keine. Es werden keine Datei-, Text-, PII- oder Mapping-Daten übertragen.
  • Keine Drittanbieter-Domains, keine Analytics, kein Error-Tracking.

Welche Daten gespeichert werden

  • Dokumentinhalte: werden nicht gespeichert; sie liegen während der Verarbeitung im Arbeitsspeicher und werden beim Zurücksetzen / nach dem Download verworfen.
  • Service-Worker-Cache: speichert ausschließlich die eigenen statischen Dateien für den Offline-Betrieb – niemals Dokumentinhalte.
  • Keine Cookies, kein localStorage, kein IndexedDB für Dokumentdaten.

Wann Daten verworfen werden

  • Objekt-URLs für Downloads werden mit URL.revokeObjectURL() freigegeben.
  • Beim Zurücksetzen (oder Laden einer anderen Datei) werden Referenzen auf das vorherige Dokument gelöst; der Web Worker wird beendet.
  • Schließen des Tabs verwirft alles (nichts wird persistiert).

Mapping-/Report-Datei (optionaler Export)

Exportieren Sie die Ersetzungstabelle (CSV/JSON), enthält diese Datei selbst personenbezogene Daten (die Originalwerte) und kann pseudonymisierte Ausgaben re-identifizieren. Die App weist vor dem Export darauf hin. Bewahren und teilen Sie die Datei entsprechend geschützt auf.

Drittanbieter-Abhängigkeiten

  • MVP: keine zur Laufzeit. Für die TXT-Verarbeitung wird kein Drittanbieter-JavaScript ausgeliefert.
  • Künftige Dokument-Bibliotheken (PDF/DOCX/XLSX) werden selbst gehostet (kein CDN), versioniert und hinsichtlich Netzwerkverhalten, Lizenz und Wartungsstatus geprüft.
